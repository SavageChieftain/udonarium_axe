# パネル機能

FAB メニュー（左端のハンバーガーボタン）から開く主なパネルです。
パネルはタイトルバーをドラッグで移動、端をドラッグでリサイズでき、複数同時に開けます。

## テーブル設定

テーブルの作成と見た目を設定します。

- **テーブル名** の変更、**新しいテーブル** の作成・切り替え
- **グリッド種類**（四角 / ヘクスなど）、**グリッド常時表示**、**スナップ設定**
- **テーブル幅 / 高さ** のスライダー
- **背景フィルタ**（距離ビューの色味）
- 設定後は **保存** で反映

## 画像

コマやテーブルに使う画像を管理します。

- ドロップゾーンに画像をドラッグ＆ドロップ、またはクリックして選択してアップロード
- **タグ** で画像を分類（タグの追加・変更が可能）
- アップロード画像は WebP に変換して保持されます

## ジュークボックス（音楽）

BGM / SE を再生・管理します。

- **試聴 / BGM / SE** など複数の音量スライダー
- **ライブラリ / 再生リスト** タブの切り替え
- 音楽ファイルをドロップゾーンへ追加
- BGM はシーク位置を含めて参加者間で同期され、ミニプレイヤーでも操作できます

## インベントリ

テーブル上のコマやオブジェクトを一覧で管理します。

- タブ（テーブル上 / 共有 / 個人 など）で表示を切り替え
- 一覧から行き先ボタンで一括移動
- キャラクター単位で「インベントリ非表示」「非トーク」を切り替え

## カットイン

演出用のカットイン（画像・動画・音声）を作成・再生します。
チャットから `@名前` で音声のみのカットインを呼び出すこともできます。

## 保存と読み込み

- **保存** — ルーム全体を zip で書き出します
- **ZIP 読込** — 書き出した zip や xml を読み込んでルームに反映します
