# 保存と読み込み

ルームの状態を書き出して保存したり、保存データを読み込んで復元したりできます。

## 保存

FAB メニューの **「保存」** を押すと、ルーム全体が zip ファイルとして書き出されます。
テーブル・コマ・カード・チャットなどの状態がまとめて含まれます。

## ZIP 読込

FAB メニューの **「ZIP 読込」** から、書き出した zip や、コマ・コマ集の xml を読み込んでルームに反映できます。
配布されたキャラクターデータ（zip / xml）を取り込むときにも使います。

## 個別の書き出し

- キャラクターは、シートの保存からコマ単位で zip 書き出しできます
- チャットログは [チャットの基本](/manual/chat) の HTML ログ書き出しを利用します

> ゲームデータは P2P で共有される一方、中央サーバーには保存されません。
> セッションを残したいときは、こまめに「保存」で手元に書き出しておくと安心です。
