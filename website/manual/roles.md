# ロール（GM / プレイヤー / 見学）

参加者には **ゲームマスター（GM）／プレイヤー（PL）／見学** の 3 つのロール（役割）があります。ロールによって、できる操作や見える情報が変わります。ロールは参加者全員で同期され、[接続パネル](/manual/#画面の見かた)（接続情報）から設定します。

| ロール               | 主な権限                                                                             |
| -------------------- | ------------------------------------------------------------------------------------ |
| ゲームマスター（GM） | すべての操作が可能。隠し情報やシークレットも閲覧でき、公開範囲・オーナーを管理できる |
| プレイヤー（PL）     | 通常の操作（コマの移動・作成・編集・チャットなど）                                   |
| 見学                 | 読み取り専用。閲覧はできるが、卓上の操作や編集は一切できない                         |

## 自分のロールを設定する

FAB メニューの **接続** から接続パネルを開くと、自分の名前の下に **役割** の選択ボタン `GM / PL / 見学` が並びます。**プレイヤーと見学はいつでも自由に切り替えられ**、その場で全員に反映されます。

- **GM は自分では選べません。** ほかに GM がいる間、GM ボタンは押せません（横取り防止）。GM になるには、既存の GM に割り当ててもらうか、自分で **部屋を作成** します。
- 部屋を新しく作成した人は、自動的に **GM** になります。
- 設定は部屋に入る前からでき、見学やプレイヤーをあらかじめ選んでおけます。

## GM が他の参加者のロールを変更する

GM のときは、接続パネルの **参加者一覧** で各参加者の右側にロールの選択メニューが表示され、他の参加者を GM / PL / 見学 に変更できます。

参加者一覧やカーソルには、ロールが色付きのバッジ（GM / PL / 見学）で表示されるので、誰がどの役割かひと目で分かります。

## 各ロールでできること

### 見学（読み取り専用）

見学は卓の様子を見るための役割で、**一切の操作ができません**。

- コマ・カード・ダイスなどの **移動・回転・作成・削除・複製** ができません
- 右クリックのコンテキストメニュー、詳細・編集パネルの入力、ファイルの読み込みなどができません
- チャットの閲覧や、テーブルの閲覧は可能です
- **チャットログの保存（書き出し）は、ロールに関わらず誰でも行えます**
- 暗闇が有効な卓では、[全プレイヤーの視界を合成した範囲](/manual/vision-lighting)が見えます

### ゲームマスター（GM）

GM は卓の進行役として、ほかの参加者には隠れている情報も確認できます。

- [インベントリ](/manual/inventory) で非表示にしたキャラクター
- シークレットダイスの出目、シークレットチャットの内容、隠した名前
- [公開範囲](/manual/disclosure) を「GMのみ」「特定プレイヤー」に設定した情報

さらに GM 向けの管理機能として、[オブジェクト一覧（GM）](/manual/gm-object-list)で全オブジェクトを俯瞰・管理でき、[チャット](/manual/chat)はタブごとに閲覧・発言できるロールを設定できます。

#### GM ツールバー

GM のときは画面上部に **GM ツールバー** が表示され、よく使う GM 機能にすぐアクセスできます（ドラッグで移動可能）。

- **オブジェクト一覧** — [全オブジェクトの俯瞰・管理](/manual/gm-object-list)
- **マップエディター** — セル・図形・スタンプなどを組み合わせて[マップを描き起こす](/manual/map-maker)
- **NPC バー** — NPC のアイコンを並べ、クリックでチャットパレットを素早く呼び出し／切り替え
- **暗闇の ON / OFF** — テーブルの[暗闇](/manual/vision-lighting)をワンクリックで切り替え
- **ペルソナ** — 特定のプレイヤー・見学から卓がどう見えるかを[プレビュー](/manual/vision-lighting)
- **オフラインの所有を解放** — 接続していないオーナーの[所有をまとめて解除](/manual/disclosure#オーナー)（途中で抜けて入り直した人の手当てに）

## GM がいなくなったとき

GM が退室・切断などでいなくなると、シークレットや隠し情報は誰にも見えない状態になり、卓は GM の復帰を待ちます。

- **ロールはタブを開いたままの再接続なら自動で復帰します。** ページを再読み込みした場合も、同じ部屋に入り直せば元のロールに戻ります。
- **GM が一人もいなくなると、GM ボタンが押せるようになります。** 残った参加者の誰かが自分を **GM** に設定して進行を引き継げます（GM が戻れば、再び横取りはできなくなります）。

::: tip 表示される ID について
ユーザー ID は内部的には長い識別子ですが、画面では先頭 6 文字の短い ID で表示されます。完全な ID はマウスを乗せると確認できます。
:::
