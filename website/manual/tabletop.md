# 視点とテーブル操作

## 視点を動かす

テーブル（中央の 3D の場）は、次の操作で見回せます。

- **回転 / 移動** — テーブルの何もない場所をドラッグ
- **ズーム** — マウスホイール
- **2D 表示** — [テーブル設定](/manual/table-setting) から真上視点（2D トップダウン）に切り替え

<Shot src="table" alt="森を俯瞰したテーブルにキャラクターとモンスターのコマが並んでいる" caption="ドラッグで視点を回し、ホイールで寄り引きします" />

## グリッドとスナップ

グリッドの表示・種類（四角 / ヘクス）やスナップの効き方は [テーブル設定](/manual/table-setting) で調整します。これらはテーブルごとに参加者間で同期されます。

## オブジェクトを置く

テーブルの何もない場所を**右クリック**すると、作成メニューが開きます。

<Shot src="table-context-menu" width="620" alt="テーブルの何もない場所を右クリックしたときの作成メニュー" caption="何もない場所を右クリックすると、置けるものが並びます" />

- **キャラクターを作成** → [キャラクターコマ](/manual/character)
- **ダイスを作成** → [ダイス](/manual/dice)
- **共有メモを作成** → [共有メモ](/manual/notes)
- **トランプの山札を作成** → [カード](/manual/cards)
- **射程範囲を作成** → [射程範囲](/manual/range)
- **マップマスクを作成** → [マップマスク](/manual/map-mask)
- **地形を作成** → [地形](/manual/terrain)

置いたあとの移動・回転・複数選択など共通の操作は [オブジェクトの基本操作](/manual/objects) を参照してください。
