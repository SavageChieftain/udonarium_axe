# テーブルとオブジェクト

## 視点を動かす

テーブル（中央の 3D の場）は、次の操作で見回せます。

- **回転 / 移動** — テーブルの何もない場所をドラッグ
- **ズーム** — マウスホイール
- **2D 表示** — テーブル設定から真上視点（2D トップダウン）に切り替え可能

## オブジェクトを置く

テーブルの何もない場所を**右クリック**すると、作成メニューが開きます。主な作成項目:

- **キャラクターを作成** — キャラクターコマ
- **ダイスを作成** — D4 / D6 / D8 / D10 / D12 / D20 などのダイスシンボル
- **共有メモを作成** — テーブル上に貼るメモ
- **トランプの山札を作成** — カードの山札
- **マップマスクを作成** — 隠し領域（スクラッチで開けられる）
- **地形を作成** — 地形・壁オブジェクト

作成すると、右クリックした位置にオブジェクトが現れます。

## 動かす・回す・重ねる

- **移動** — オブジェクトをドラッグ
- **回転** — オブジェクトにマウスを乗せると現れる回転ハンドルをドラッグ（2D 表示中は無効）
- **高さ（高度）** — 一部オブジェクトはコンテキストメニューの「高度設定」で上下に積めます
- **複数選択** — `Ctrl + クリック` で複数を選択し、まとめてドラッグ・複製・移動

各オブジェクトを**右クリック**すると、そのオブジェクト専用のメニュー（コピー・削除・詳細表示など）が開きます。
詳しくは [キャラクターコマ](/manual/character)、[カード](/manual/cards)、[ダイス](/manual/dice)、[共有メモ](/manual/notes) を参照してください。
