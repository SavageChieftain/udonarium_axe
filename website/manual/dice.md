# ダイス

テーブル上にダイスシンボルを置いて振ったり、チャットからダイスボットを呼び出したりできます。

## ダイスシンボルを置く

テーブルの何もない場所を右クリックし、「ダイスを作成」から種類を選びます。

- D4 / D6 / D8 / D10 / D12 / D20 などに対応
- 置いたダイスはドラッグで移動でき、振った出目は参加者間で共有されます
- 名前・所有者のラベルはカメラの向きに追従します

## ダイスシンボルシート

ダイスシンボルは、面ごとに画像を割り当てた**シート**として設定・保存・複製できます。
オリジナルの目（アイコンや記号など）を使ったダイスを用意したいときに利用します。

## コイン

表か裏かだけを決めたいときは、ダイスの代わりにコインを使えます。

テーブルの何もない場所を右クリックして **コインを作成** を選ぶと、その位置に金色のコインが置かれます。

- **投げる** — コインを**ダブルクリック**するか、右クリックの **コインを投げる** を選びます。コインが浮き上がって 5 回転し、着地した面が結果です
- **結果はチャットへ** — 「（誰が）コインを投げました → 表」がシステムメッセージとして流れます。アニメーションは参加者全員の画面で同時に再生されるので、後から出目を書き換えたように見えることはありません
- **面を決め打つ** — 右クリックの **表にする** / **裏にする** で、投げずに向きだけ変えられます
- **絵柄を変える** — 右クリックの **コインを編集** でシートが開きます。表面・裏面それぞれに画像を割り当てられ、**画像を外す**と金色のコインに戻ります。名前と大きさもここで変えられます

コインはテーブルのオブジェクトなので、ドラッグで動かしたり、固定・コピー・削除したり、[部屋の保存](/manual/save-load)に含めたりできます。

## チャットでダイスを振る

チャット欄にコマンド（例: `2d6`）を打ち込んで振る方法は、[ダイスボット](/manual/dicebot) を参照してください。
