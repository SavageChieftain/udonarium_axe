# ダイス

テーブル上にダイスシンボルを置いて振ったり、チャットからダイスボットを呼び出したりできます。

## ダイスシンボルを置く

テーブルの何もない場所を右クリックし、「ダイスを作成」から種類を選びます。

- D4 / D6 / D8 / D10 / D12 / D20 などに対応
- 置いたダイスはドラッグで移動でき、振った出目は参加者間で共有されます
- 名前・所有者のラベルはカメラの向きに追従します

## ダイスシンボルシート

ダイスシンボルは、面ごとに画像を割り当てた**シート**として設定・保存・複製できます。
オリジナルの目（アイコンや記号など）を使ったダイスを用意したいときに利用します。

## チャットでダイスを振る（ダイスボット）

チャット欄にコマンドを打ち込むと、[BCDice](https://github.com/bcdice/BCDice) が結果を返します。

- `2d6` … 6 面ダイスを 2 個
- `1d100<=50` … 成功判定
- ゲームシステムを選ぶと、その固有コマンドも利用できます

詳しくは [チャットとダイスボット](/manual/chat) を参照してください。
