# チャットの基本

<Shot src="chat" alt="チャットウィンドウ。発言とダイスロールの結果が並んでいる" width="520" caption="発言とダイスの結果が同じ流れに並びます" />

チャットウィンドウは起動時に左下へ自動で開きます。FAB メニューの「チャット」からも開けます。

## 発言する

下部の入力欄に文字を入れて **送信** ボタン、または `Enter` で発言します。

- `Enter` … 送信
- `Shift + Enter` … 改行
- `Ctrl + ↑ / ↓` … 入力履歴をたどる
- `Ctrl + ← / →` … タブを切り替え

発言者（キャラクター）や送信先、文字色は入力欄まわりのセレクト・**色設定**から選べます。
入力欄は縦リサイズでき、高さは記憶されます。

### 色設定

入力欄の丸いスウォッチが 3 つの持ち色で、押すとその色で発言します。歯車の **色設定** から中身を変えられます。

パネルは **1 色ずつ**編集します。上の 3 つのボタンがそれぞれの色を着ているので、3 色すべてを見ながら、選んだ 1 色について次を決められます。

- **文字色** — 16 色のスウォッチから選ぶか、右のピッカーで任意の色にする
- **吹き出し** — ライトテーマ用とダークテーマ用を別々に決められる

吹き出しは既定では**その文字が読める明るさへ自動で決まります**。テーマがライトなら明るい側、ダークなら暗い側に寄ります。手で決めたあと自動に戻したいときは、吹き出しの色の隣の戻すボタンを押します。

読みにくい組み合わせにだけ警告が出ます。押すとその場で読める吹き出しに直ります。

## タブ

上部のタブで会話を分けられます。あふれた場合は左右の矢印でスクロールします。

タブの上でマウスホイールを回すと、隣のタブに移ります。こちらは端まで来ると止まります（`Ctrl + ← / →` は
最後のタブから最初のタブへ一周します）。移った先のタブは自動で見える位置まで送られます。

### システムタブ

**入退室・再接続・無応答などの知らせ**は、専用の「システム」タブに出ます。会話のタブに混ざらないので、
誰かが抜けるたびに読んでいたやり取りが流れてしまうことがありません。

- **消せません**（消すと知らせの行き先が無くなり、会話のタブへ戻ってきます）
- **「全タブ」のログ書き出しには入りません**。必要なときは、システムタブを選んで「このタブ」で書き出してください
- **名前と位置は固定**です（名前は「システム」、位置は末尾）
- **誰も書き込めません**。全員が閲覧でき、見せる相手を選ぶ設定もありません
- **部屋データには保存されません**。以前の部屋データを読み込んだときも、システムタブは 1 枚だけ用意されます

なお、ラウンド開始・手番・バフの失効といった**卓の進行の告知**は会話の一部なので、これまでどおりメインタブに出ます。

## タブの権限（閲覧・発言）

タブごとに、[ロール](/manual/roles)別の **閲覧** と **発言** を設定できます（歯車 →「タブ設定」→ 各タブの「閲覧・発言の権限」）。

| 役割       | 閲覧  | 発言  |
| ---------- | ----- | ----- |
| プレイヤー | ☑ / ☐ | ☑ / ☐ |
| 見学       | ☑ / ☐ | ☑ / ☐ |

- **この権限を変更できるのは GM・プレイヤーだけです。**[見学](/manual/roles)は読み取り専用のため、チェックボックスが無効表示になり権限を編集できません。
- **GM は常にすべてのタブを閲覧・発言できます**（設定の対象外）。
- 既定は、プレイヤー＝閲覧・発言とも可、見学＝閲覧のみ可（発言不可）です。
- **閲覧できないタブ**は、そのロールのタブ一覧に表示されません。表示中のタブが閲覧できなくなった場合は、自動的に閲覧できる別のタブへ切り替わります。
- **発言できないタブ**では、入力欄が「閲覧のみ」の表示になり発言できません。
- 「発言」を許可すると「閲覧」は自動的に許可されます（発言だけ可・閲覧不可の状態は作れません）。
- **システムタブにはこの設定がありません**。全員が閲覧でき、誰も発言できません。

## 設定（歯車アイコン）

歯車から「タブ設定」「ダイス表設定」「チャット設定」を開けます。チャット設定では次を変えられます。

- **文字サイズ** — 10 から 24 まで。通常表示と簡易表示の両方に同時に効きます
- **立ち絵** — 表示するか（タブごと）、大きさ、ウィンドウ内に置くか、ウィンドウ外の立ち絵を保持するか
- **簡易表示** — 有効にするか（タブごと）、時間と ID を出すか
- **スクロール位置を最新に追従** — 新着発言に自動追従するか。最下段にいるときだけ追従し、ログを遡って読んでいる間は追従を止めます
- **システムちゃん** — システムメッセージとダイスの隣に立つ絵。ここだけは部屋で共有されます（次節）

これらと発言の色は**この端末に保存**され、次に開いたときも同じ見た目で始まります。タブごとの設定はタブ
単位で覚えるので、同じ部屋を開き直せば前と同じです（直近 64 タブ分）。

自分の画面だけの設定なので、部屋のデータには入らず、他の参加者にも送られません。

## システムちゃん

システムメッセージとダイスの結果に表示される絵が、システムちゃんです。チャット設定の **システムちゃん** から、表示するかどうかと絵そのものを部屋ごとに設定できます。

- **システムちゃんを表示** — 外すと絵が出なくなります。文面はそのまま残ります
- **通常メッセージ / ダイスロール** — 2 枚は別々に差し替えられます。**変更** で画像一覧から選び、**既定に戻す** で同梱の絵へ。画像一覧で「画像なし」を選べば、その場面だけ絵を出さない指定になります
- **発言キャラクター・プレイヤーの立ち絵を表示** — システムちゃんが出る場面を、振った人の絵に差し替えます。振ったキャラクターの絵が先で、無ければその人のアイコン

チャットログのシステムちゃんを右クリックしても同じです。[ビジュアルノベルモード](/manual/visual-novel)の立ち絵からも呼べます。

歯車の他の項目と違い、ここは**部屋の全員に共有され、部屋データにも保存されます**。変更できるのは卓を編集できる人だけです。[見学](/manual/roles)からは触れません。

## 発言の操作

各発言から **編集 / 返信 / 引用 / 元発言へジャンプ / メモとして共有** が行えます。
発言に**画像を添付**することもできます。

## ログの書き出し

送信者ポートレートを埋め込んだ **HTML ログ**を書き出せます（引用・返信の関係も可視化されます）。「このタブ」または「全タブ」をまとめて出力できます。

GM 以外が書き出す場合、**自分が閲覧できるタブだけ**が対象になります（「全タブ」も閲覧可能なタブのみ。閲覧できないタブは「このタブ」ボタンも無効になります）。

**「全タブ」にシステムタブは入りません**（入退室の知らせで読み返したいやり取りが沈むためです）。
