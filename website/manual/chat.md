# チャットとダイスボット

チャットウィンドウは起動時に左下へ自動で開きます。FAB メニューの「チャット」からも開けます。

## 発言する

下部の入力欄に文字を入れて **送信** ボタン、または `Enter` で発言します。

- `Enter` … 送信
- `Shift + Enter` … 改行
- `Ctrl + ↑ / ↓` … 入力履歴をたどる
- `Ctrl + ← / →` … タブを切り替え

発言者（キャラクター）や送信先、文字色は入力欄まわりのセレクトから選べます。

## ダイスを振る（ダイスボット）

入力欄にダイスコマンドを打ち込むと、[BCDice](https://github.com/bcdice/BCDice) が結果を返します。

- `2d6` … 6 面ダイスを 2 個
- `1d100<=50` … 成功判定
- ゲームシステムを選ぶと、その固有コマンドも利用できます

ダイス表は「ダイス表設定」から登録できます。

## タブと設定

- **タブ** — 上部のタブで会話を分けられます。あふれた場合は左右の矢印でスクロール。
- **設定（歯車アイコン）** — 「タブ設定」「ダイス表設定」「チャット設定」を開けます。
- **スクロール追従** — チャット設定の「スクロール位置を最新に追従」で、新着発言に自動追従するかを切り替えます。最下段にいるときだけ追従し、ログを遡って読んでいる間は追従を止めます。

## その他

- **編集 / 返信 / 引用 / 元発言へジャンプ / メモとして共有** — 各発言の操作から行えます
- **画像の添付** — 発言に画像を添付できます
- **投票・アラーム** — チャットウィンドウ上部のボタンから開きます
- **HTML ログ書き出し** — 送信者ポートレートを埋め込んだログを書き出せます
