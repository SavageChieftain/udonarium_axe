# チャットパレット

キャラクターごとに、よく使う発言や判定コマンドを並べておける入力補助です。

## 開く

キャラクターコマを**右クリック** → **「チャットパレットを表示」** で開きます。
パレットには専用のチャット入力欄があり、行をクリックするとその内容を送信できます。

## 編集する

- 鉛筆（edit）アイコンで**編集モード**に切り替えると「編集中」と表示され、コマンド一覧を直接書き換えられます
- **見出し** ボタンで見出し行を挿入
- **キャラ情報** ボタンで、そのキャラのデータを参照するビューに切り替え（**パレットに戻る**で戻る）

登録したコマンドはキャラクターに紐づいて保存され、ダイスボットのコマンド（例: `2d6`）もそのまま使えます。
ダイスの記法は [ダイスボット](/manual/dicebot) を参照してください。
