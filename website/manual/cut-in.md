# カットイン

画像・動画・音声による演出（カットイン）を作成・再生します。FAB メニューの「カットイン」から開きます。

## カットインを作る

カットイン一覧から新規作成し、表示する画像／動画（YouTube 含む）や音声、表示位置・大きさなどを設定します。

## 再生する

- 一覧から選んで再生
- チャット起動を許可したカットインは、チャットの文末に名前を打って再生できます — `名前` で映像つき、`@名前` で**音声のみ**（詳細は[チャットの特殊記法](/manual/chat-syntax#カットイン起動)）
- テーブルを切り替えたときに流すこともできます（[テーブル設定](/manual/table-setting)）

## 枠なしで流す

表示設定の **枠なしで表示** を入れると、タイトルバーも枠線も背景も消えます。残るのは絵だけ。クリックはそのまま下へ抜けるので、演出が流れている最中でもコマを動かしたり地形を並べ替えたりと、卓の操作を止めずに済みます。

代わりに閉じるボタンがなくなります。終わらせる道は 4 つ。

- 再生時間（秒）を決めておく
- ループを切って、動画かシーンが終わるのを待つ
- 一覧の **停止** を押す
- 同じタグの別カットインを流して置き換える

ループを入れたまま再生時間を 0 にすると、出っぱなしになります。誰かが止めるまで消えません。

## レイヤーを重ねて組み立てる

編集画面の **シーン** タブでは、1 枚絵ではなく複数のレイヤーを重ねたカットインを作れます。画像・文字・帯の 3 種類を足し、ステージ上でドラッグして置き、四隅をつまんで大きさを変えます（Shift を押しながらだと縦横比が保たれます）。

左のレイヤー一覧は上が手前です。行をドラッグすれば重なり順が変わります。目のアイコンで一時的に隠せますし、錠前を掛けたレイヤーはステージ上でつかめなくなるので、下に敷いた背景を触ってしまう事故を防げます。

レイヤーを 1 枚でも足すと、そのカットインは「元サイズで表示」をやめます。1 枚の画像の寸法に合わせる意味がなくなるためです。

### 動かす

下のタイムラインが尺です。プロパティ欄の各項目の右にある ◆ を押すと、再生ヘッドの位置にキーが打たれます。あとは再生ヘッドを動かして値を変え、そこでもう一度 ◆ を押すだけ。2 つのキーの間をレイヤーが動きます。

キーを打てるのは **X / Y・拡大率・回転・不透明度・ぼかし** です。タイムライン上の ◆ はドラッグで前後に動かせます。消すときはダブルクリック。

キーの上に再生ヘッドがあるときは **補間** の欄が出ます。等速のほか、ゆっくり終わる、行き過ぎて戻る、瞬間的に切り替わる、といった動き方を選べます。選んだ動き方は、その位置に立っているすべてのキーへまとめて書き込まれます。位置と不透明度がばらばらの曲線で動いてしまうのを防ぐためです。

レイヤーごとの **開始 ms / 終了 ms** を決めれば、途中から出したり途中で消したりできます。終了 0 は「シーンの最後まで」の意味です。

組み立てたカットインは、[リプレイ](/manual/replay)の動画書き出しにもそのまま出ます。

### やり直し

Ctrl+Z で 1 手戻り、Ctrl+Shift+Z（または Ctrl+Y）で進みます。ドラッグ 1 回は、途中で何度画面が動いても 1 手です。Delete は選択中のレイヤーを消します。スペースは再生と停止。

::: warning 2 人で同時に編集すると
シーンは参加者全員で共有されます。同じシーンを 2 人が同時にいじると、あとから書いたほうが残ります。元に戻す操作も相手の変更ごと巻き戻すので、1 人ずつ編集してください。
:::

## 音量

- カットインの動画音量は調整でき、YouTube の音量は BGM とは独立して管理されます（既定 50）

BGM 本体の管理は [ジュークボックス](/manual/jukebox) を参照してください。
