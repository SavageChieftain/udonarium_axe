# テーブル設定

FAB メニューの「テーブル設定」から開きます。テーブルの作成と見た目をまとめて設定します。

## テーブルの作成・切り替え

- **新しいテーブルを作る** — テーブルを追加
- 一覧から選んで使用テーブルを切り替え
- **テーブル名** の変更

## グリッド

- **グリッド種類** — 四角 / ヘクス など
- **グリッド常時表示** の切り替え
- **スナップ設定** — セル中心 / 頂点 / セル＋頂点 / ALL（セル・頂点・辺の中点を統合）
- グリッドのフォントカラー

## 大きさ・背景

- **テーブル幅 / 高さ** のスライダー
- **背景フィルタ**（距離ビューの色味）
- 背景画像の設定

設定したグリッド・スナップ・サイズはテーブルごとに参加者間で同期されます。最後に **保存** で反映してください。
