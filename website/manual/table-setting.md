# テーブル設定

FAB メニューの「テーブル設定」から開きます。テーブルの作成と見た目をまとめて設定します。

## テーブルの作成・切り替え

- **新しいテーブルを作る** — テーブルを追加
- 一覧から選んで使用テーブルを切り替え
- **テーブル名** の変更

## グリッド

- **グリッド種類** — 四角 / ヘクス など
- **グリッド常時表示** の切り替え
- **スナップ設定** — セル中心 / 頂点 / セル＋頂点 / ALL（セル・頂点・辺の中点を統合）
- グリッドのフォントカラー

## 大きさ・背景

- **テーブル幅 / 高さ** のスライダー
- **背景フィルタ**（距離ビューの色味）
- 背景画像の設定

## グリッドに合わせて設定

床画像の横の **「グリッドに合わせて設定」** ボタンから、マップ画像のグリッド位置を視覚的に合わせる調整ツールを開けます。

1. **画像を選択** — ファイル選択画面で合わせたい床画像を選ぶ
2. **固定グリッドに画像を合わせる** — アバター画像の切り抜きと同じ要領で、グリッドの「枠」は動かさず**画像のほうを動かして**合わせます
   - **マス数で合わせる** — マップの横マス数または縦マス数を直接入力すると、画像が自動で拡縮・配置されます（「このマップは 16×12」と分かっているときの最短ルート）
   - **画像をドラッグ**して位置を移動
   - **ホイールで拡大縮小**（カーソル位置を中心にズーム。Shift+ホイールで微調整）。ズームはスライダー・％入力でも指定できます
   - 矢印キーで画像を 1px ずつ移動（Shift キーで 10px ずつ）
   - 「リセット」で初期表示に戻す
   - グリッドのマスを完全に覆っている範囲だけが切り出し対象になり、それ以外は暗く表示されます
3. **「設定」を押して確定** — 整数マスに収まる領域を切り出した画像がファイルストレージに追加され、テーブルの背景画像・幅・高さが自動設定されます

::: tip マップメーカーと組み合わせて使う
[マップメーカー](/manual/map-maker)で書き出した画像を床画像に設定した場合も、このツールでグリッド位置を細かく調整できます。
:::

## 暗闇（視界・照明）・壁

- **暗闇（視界・照明）** — テーブルを暗くして、視界や光源で照らされた範囲だけを見せる
- **壁** — 四方（北壁 / 東壁 / 南壁 / 西壁）の表示と壁画像

詳しい使い方は [暗闇・視界・光源](/manual/vision-lighting) を参照してください。

設定したグリッド・スナップ・サイズはテーブルごとに参加者間で同期されます。最後に **保存** で反映してください。
