# マップマスク

マップの一部を隠しておき、必要なときに削って公開できる目隠しです。
未踏エリアの隠蔽や、徐々に開示するマップに使います。

## マップマスクを置く

テーブルの何もない場所を右クリックし、「マップマスクを作成」を選びます。
作成したマスクはドラッグで移動・リサイズできます。

## スクラッチ（削って公開）

マスクを**右クリック**して操作します。

1. **スクラッチ開始** — 削り取りモードに入る（マスクの所有者が自分になる）
2. マスク上を**ドラッグ**して、見せたい部分を削る
3. **スクラッチ確定** — 削った状態を確定する

確定するまでは自分だけが削り途中の状態を編集できます。マスク全体は移動・コピー・削除など [オブジェクトの基本操作](/manual/objects) も可能です。
