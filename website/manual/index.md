# 操作マニュアル

Udonarium Axe の画面構成と基本操作をまとめた操作マニュアルです。
導入（SkyWay・バックエンド・配置）がまだの場合は、先に [クイックスタート](/guide/quickstart) を済ませてください。

## 画面の見かた

ルームを開くと、3D のテーブルを中心に、左側へ接続パネルとチャットウィンドウが自動で開いた状態になります。

- **テーブル（中央）** — コマ・カード・ダイスなどを置く 3D の場。ドラッグで視点移動、ホイールでズームします。
- **接続パネル（左上）** — ニックネーム・アイコン・ユーザー ID の設定、ロビー表示。
- **チャットウィンドウ（左下）** — 発言・ダイス・各種設定への入口。
- **FAB メニュー（左端の丸いハンバーガーボタン）** — 各種パネルを開くメインメニュー。

## FAB メニュー

左端のハンバーガーボタンを押すと、機能パネルを開くメニューが縦に展開します。

| 項目             | 内容                                                |
| ---------------- | --------------------------------------------------- |
| 接続             | ニックネーム・アイコン・ロビー（接続パネル）        |
| チャット         | チャットウィンドウ                                  |
| テーブル設定     | テーブルの作成・グリッド・背景などの設定            |
| 画像             | 画像のアップロードと管理                            |
| ジュークボックス | BGM / SE の再生と管理                               |
| カットイン       | カットイン演出の作成・再生                          |
| インベントリ     | コマやオブジェクトの一覧管理                        |
| ZIP 読込         | 保存データ（zip / xml）の読み込み                   |
| 保存             | ルーム全体を zip で書き出し                         |
| テーマ           | 自動 / ダーク / ライト の切り替え（クリックで循環） |
