# マップエディター

マップエディターは、セル・図形・スタンプ・フリーハンドなどを組み合わせてマップ画像を描き起こす **GM 専用ツール**です。GM ツールバーの **マップエディター** ボタンから開きます（[ロール](/manual/roles)が GM のときのみ表示されます）。

## 画面構成

パネルは 4 列 2 行のレイアウトで構成されています。

| 領域                   | 内容                                                |
| ---------------------- | --------------------------------------------------- |
| ツールバー（左列）     | 描画ツール選択ボタン（12 種）                       |
| プロパティ（左2列目）  | 選択ツールに応じた塗り・線・スタンプなどの設定      |
| キャンバス（中央）     | 実際の描画エリア。ホイールでズーム（Ctrl+ホイール） |
| レイヤー（右列）       | レイヤーの管理（表示・ロック・不透明度・並び替え）  |
| ステータスバー（下段） | アンドゥ/リドゥ・ズーム・JSON 操作・書き出しボタン  |

## 12 種の描画ツール

| ツール       | 操作                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| 選択         | クリックでアイテムを選択。ドラッグで移動。Delete/Backspace で削除              |
| セル塗り     | クリック/ドラッグでグリッドセルを塗りつぶす                                    |
| セル消去     | クリック/ドラッグでセルの塗りを消す                                            |
| 塗りつぶし   | クリックで連続する同色セルを一括塗りつぶし（フラッドフィル）                   |
| 矩形         | ドラッグで長方形を描く。ドラッグ終了時に確定                                   |
| 楕円         | ドラッグで楕円を描く。ドラッグ終了時に確定                                     |
| 直線         | ドラッグで直線を描く。ドラッグ終了時に確定                                     |
| 多角形       | クリックで頂点を追加。Enter またはダブルクリックで確定。Esc でキャンセル       |
| 壁           | クリックで頂点を追加してポリラインの壁を引く。Enter またはダブルクリックで確定 |
| スタンプ     | スタンプを選んでクリックで配置。スナップが有効な場合はセル中心にスナップ       |
| フリーハンド | ドラッグで自由な線を引く。ドラッグ終了時に確定                                 |
| テキスト     | クリックで配置位置を決め、入力後 Enter で確定。Esc でキャンセル                |

## 塗り（フィル）

矩形・楕円・多角形・セル塗り・塗りつぶしツールでは塗りモードを選べます。

- **単色** — カラーピッカーで色を指定
- **テクスチャ** — 草地・水面・石畳・木材・砂地・土・レンガ・タイル・溶岩・雪の 10 種。拡大率と回転も調整可能

## スタンプ

6 カテゴリ 49 種のスタンプが用意されています。

| カテゴリ   | 主な内容                                     | 種類数 |
| ---------- | -------------------------------------------- | ------ |
| 扉         | 片扉・両扉・開いた扉・格子扉・隠し扉・アーチ | 6      |
| 階段       | 上り・下り・螺旋・はしご・スロープ           | 5      |
| 家具       | テーブル・椅子・ベッド・宝箱など             | 10     |
| 自然       | 樹木・岩・泉・池・キノコなど                 | 9      |
| ダンジョン | 柱・祭壇・かがり火・罠・ケージなど           | 9      |
| マーカー   | ピン・旗・スカルなどの目印                   | 10     |

配置時にプロパティパネルでサイズ・回転・X/Y 反転・色を調整できます。「色を自動」をオフにするとカラーピッカーで色を指定できます。

選択ツールで配置済みのスタンプを選ぶと、サイズ・回転・反転をあとから変更できます。

## レイヤー

各レイヤーは右列で管理します。

- **表示** — 目のアイコンで表示/非表示を切り替え
- **ロック** — 鍵アイコンでロック。ロック中はそのレイヤーに描画できません
- **不透明度** — スライダーで 0～100% を調整
- **並び替え** — 上下矢印ボタンで描画順を変更
- **名前変更** — レイヤー名をダブルクリックして編集
- **削除** — ゴミ箱アイコン。確認ダイアログあり

「＋」ボタンから追加できるレイヤーの種類: セル・図形・壁・スタンプ・フリーハンド・テキスト

## スナップとグリッド

- **スナップ** — 有効にすると図形の頂点やスタンプがグリッドに吸着します（プロパティパネルのチェックボックス）
- **グリッド表示** — キャンバスにグリッドを表示するかどうかを切り替えます
- **グリッド色** — グリッドの線色を変更できます

## アンドゥ/リドゥとキーボードショートカット

| キー操作                                            | 動作                         |
| --------------------------------------------------- | ---------------------------- |
| Ctrl+Z（macOS: Cmd+Z）                              | 元に戻す（アンドゥ）         |
| Ctrl+Y / Ctrl+Shift+Z（macOS: Cmd+Y / Cmd+Shift+Z） | やり直し（リドゥ）           |
| Delete / Backspace                                  | 選択中アイテムを削除         |
| Ctrl+ホイール（macOS: Cmd+ホイール）                | キャンバスのズーム           |
| Enter                                               | 多角形・壁を確定             |
| Esc                                                 | 描画中のドラフトをキャンセル |

## マップ設定

プロパティパネルの「マップ設定」セクションで次の値を変更できます（変更はすぐにキャンバスに反映されます）。

| 設定       | 範囲           |
| ---------- | -------------- |
| 横マス数   | 1 ～ 100       |
| 縦マス数   | 1 ～ 100       |
| マスサイズ | 16 ～ 256 px   |
| 背景色     | カラーピッカー |
| グリッド色 | カラーピッカー |

## JSON 保存・読み込み

- **JSON 保存** — 現在のマップをファイル（`map.json`）としてダウンロードします
- **JSON 読込** — 保存した JSON ファイルを読み込んでマップを復元します

## 画像書き出しと「テーブル背景に設定」

ステータスバー右側の書き出しオプションを設定してから実行します。

| オプション       | 内容                           |
| ---------------- | ------------------------------ |
| 書き出し倍率     | 1x または 2x                   |
| グリッドを含める | チェックするとグリッド線も描画 |

- **画像として保存** — 設定に従ってレンダリングした画像をファイルストレージに追加します
- **テーブル背景に設定** — 画像を書き出してファイルストレージに追加し、現在のテーブルの背景画像・幅・高さ・グリッドサイズを自動設定します

::: tip マップをテーブルに反映するには
「テーブル背景に設定」を使うと、マス数・マスサイズがそのままテーブル設定に引き継がれるため、テーブル設定を別途変更する手間がありません。
:::
