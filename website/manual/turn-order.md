# 行動順

戦闘などで「今は誰の手番か」を管理するための機能です。テーブル上のキャラクターを並び順どおりに表示し、手番が変わるたびにチャットへ通知して、対象のコマを光らせます。手番の状態は参加者全員で同期されます。

<Shot src="turn-order" alt="行動順ウィジェット。キャラクターのアイコンが順に積み重なっている" width="560" caption="ラウンド表示にすると行動順ウィジェットに切り替わります" />

## 行動順ウィジェットを開く

[インベントリ](/manual/inventory) を開き、タイトルバーのボタンで **ラウンド表示** にすると、インベントリが **行動順ウィジェット** に切り替わります。キャラクターのアイコンが行動順に積み重なって表示され、現在の手番のキャラクターがリングと淡い光で強調されます。

- 上部のうっすら色の付いたバーをドラッグして、好きな位置へ動かせます
- 元のインベントリに戻すには、同じボタンをもう一度押します（リッチ表示に戻ります）
- 表示順は、インベントリ「テーブル」タブの **並び順** がそのまま使われます（既定は敏捷度の降順、同値なら名前順）。並び順の変え方は [インベントリ](/manual/inventory) を参照してください
- 手番を回しながら全員の HP や状態異常も見たいときは [簡略表示](/manual/inventory#簡略表示は-1-体-1-行の表)にします。1 体 1 行の表になり、行動順のマーカーも各行の左に出ます

## ツールバーでの表示

戦闘中は、[GM ツールバー](/manual/roles#gm-ツールバー) と [PL ツールバー](/manual/pl-tools) にも **ラウンド数と現在の手番** が出ます。ウィジェットを開いていなくても、今が誰の番かを常に確認できます。戦闘が始まっていないあいだは表示されません。

GM ツールバーには前後の送りボタンも付いているので、進行役はウィジェットを開かずに手番を回せます。

## 手番を進める

ウィジェット上部のボタンで手番を操作します。手番が確定するたびに、対象のコマがテーブル上で光り、チャットにシステムメッセージが流れます。

- **次へ** — 行動順に沿って 1 つ進めます
- **前へ** — 1 つ戻します
- アイコンを **クリック** — そのキャラクターを直接、現在の手番にします
- **リセット** — 手番とラウンドを最初の状態へ戻します

「次へ」を押していくと、ラウンドの区切りも含めて次のように進みます。

1. **ラウンド X 開始です。**
2. **〇〇 の行動です。**（行動順に各キャラクター）
3. （最後のキャラクターまで繰り返し）
4. **ラウンド X 終了です。**
5. **ラウンド X+1 開始です。**（次のラウンドへ）

## バフの残ラウンドを自動で減らす

**ラウンドが終わるたびに、テーブル上の全員のバフ／デバフの残ラウンドが 1 ずつ減ります。**
0 になったものは自動で消え、**誰の何が切れたか**がチャットに流れます。

`3R` で付けたバフはちょうど 3 ラウンド持ちます。`&R-` や `&D` を毎ラウンド打つ必要はありません。

- **前へ**で巻き戻したときは減りません。進めたときだけ数えます
- 手番を進めた人のブラウザだけが処理するので、二重に減ることはありません
- 行動順のボタン列にある**砂時計アイコン**で、この自動減少を切り替えられます（卓全体の設定として共有されます）
- **手番で切れるバフ**は、このラウンド終了の一斉減少には含まれません。指定したキャラクターの手番が始まる
  （または終わる）ときに、そのバフだけが減ります。設定は[バフ／デバフ](/manual/buff#いつ切れるかを決める)を参照してください

::: tip 手動で操作したいとき
砂時計アイコンをオフにすると、従来どおりバフは動かなくなります。
`&R-`（全部 1 減らす）・`&D`（0 以下を消す）や[リモートコントローラ](/manual/pl-tools)のボタンで、
好きなタイミングだけ進められます。記法は[チャットの特殊記法](/manual/chat-syntax#バフ-デバフ操作)を参照してください。
:::

## インベントリ画面からの操作

行動順は、リッチ表示や簡略表示のままインベントリ「テーブル」タブからも操作できます。

- 一覧のすぐ上に **ラウンド表示・前へ・次へ・リセット** が並びます
- 現在の手番のキャラクターには、行の先頭に目印が付きます
- 各キャラクターの行のボタンから、そのキャラクターを直接 **「手番にする」** こともできます

手番の通知は [チャット](/manual/chat) のシステムメッセージとして参加者全員へ届きます。
