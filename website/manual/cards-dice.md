# カード・ダイス・共有メモ

テーブルを右クリックする作成メニューから、カードの山札・ダイスシンボル・共有メモを置けます。

## カードの山札

「トランプの山札を作成」で山札を置き、山札を**右クリック**すると操作メニューが開きます。主な操作:

- **１枚引く** — 山札からカードを 1 枚テーブルに出す
- **シャッフル** — 山札を切り直す
- **カード一覧** — 山札の中身を一覧表示
- **すべて表にする / 裏にする** — 表裏の一括切り替え
- **詳細を表示** — 山札のシートを開く
- **山札を削除する** — 山札ごと削除

引いたカードはテーブル上でドラッグして移動でき、右クリックで個別に操作できます。

## ダイスシンボル

「ダイスを作成」から D4 / D6 / D8 / D10 / D12 / D20 などを選んで配置します。
テーブル上のダイスは振って出目を共有でき、面ごとに画像を割り当てた**ダイスシンボルシート**も作成できます。

チャット欄にコマンド（例: `2d6`）を打ち込むダイスボットについては [チャットとダイスボット](/manual/chat) を参照してください。

## 共有メモ

「共有メモを作成」でテーブルに貼り付けるメモを置けます。
右クリックメニューから **編集** や **コピー**、向き（寝かせる／直立させる）の切り替え、**固定**ができます。
固定したメモはドラッグで動かせなくなります。
