# ジュークボックス（音楽）

BGM や効果音（SE）を再生・管理します。FAB メニューの「ジュークボックス」から開きます。

## 音源を追加する

ドロップゾーンに音楽ファイルをドラッグ＆ドロップ、またはクリックして選択します。
**ライブラリ** と **再生リスト** のタブで表示を切り替えられます。

## 再生と音量

- 再生・停止・シーク（再生位置の移動）・リピート
- **試聴 / BGM / SE / 全体** など複数の音量スライダー
- 「全体音量の変更を有効化」で部屋全体の音量も操作可能

## 同期とミニプレイヤー

- BGM はシーク位置を含めて参加者間で同期されます（必要に応じてクロスフェード）
- 最小化できる**ミニプレイヤー**でも操作できます

BGM と独立して鳴らす演出は [カットイン](/manual/cut-in) を参照してください。
