# v1.13.0

2026-06-10 リリース

参加者の **ロール（GM / プレイヤー / 見学）** を中心に、情報の公開範囲・オーナー、GM 向けの管理ツール、暗闇・視界・光源、効果音（SE）など、卓の進行を支える仕組みをまとめて追加した大型アップデートです。

## ✨ 新機能

### 参加者ロール（GM / プレイヤー / 見学）

参加者に **ゲームマスター（GM）／プレイヤー（PL）／見学** の 3 つの役割を追加しました。ロールによって、できる操作や見える情報が変わり、設定は参加者全員で同期されます。

- **プレイヤーと見学はいつでも自由に切り替え**できます。見学は読み取り専用で、卓上の操作や編集は一切できません。
- **GM は横取りできません。** ほかに GM がいる間は GM ボタンを押せず、GM になるには既存の GM に割り当ててもらうか、自分で部屋を作成します（作成者は自動的に GM）。
- **GM が一人もいなくなると、残った誰かが自分を GM に設定して進行を引き継げます。** タブを開いたままの再接続なら、ロールは自動で復帰します。

詳しくは [ロールのマニュアル](/manual/roles) を参照してください。

### 情報の公開範囲とオーナー

キャラクター・[共有メモ](/manual/notes)・[カード](/manual/cards)・[ダイス](/manual/dice) に、**「誰に見せるか」** を表す公開範囲（**全員 / 特定PL / GMのみ**）と **オーナー（持ち主）** を設定できるようになりました。GM が用意した NPC や情報を、必要なときに必要な相手だけへ開示する、ハンドアウトのような使い方ができます。

- 公開範囲外の参加者からは、**存在は分かるが中身は確認できない**状態になります。
- **オーナーのいない（無主の）オブジェクトは、プレイヤーが自分で取得（クレーム）**できます。
- **[保存データを読み込んだ直後](/manual/save-load)は全オブジェクトが無主**になるので、各自が自分のコマを取り直せます。
- 途中で抜けて入り直した人のために、GM は **オフラインのオーナーの所有をまとめて解放**できます。

詳しくは [情報の公開範囲のマニュアル](/manual/disclosure) を参照してください。

### GM ツール

GM の進行を助ける専用ツールを追加しました。

- **GM ツールバー** … 画面上部に表示され、よく使う GM 機能へすぐにアクセスできます（ドラッグで移動可能）。
- **[オブジェクト一覧（GM）](/manual/gm-object-list)** … 卓上の全オブジェクトを一覧で俯瞰・管理できる GM 専用パネル。
- **NPC バー** … NPC のアイコンを並べ、クリックで[チャットパレット](/manual/chat-palette)を素早く呼び出し・切り替え。
- **ペルソナプレビュー** … 特定のプレイヤー・見学から卓がどう見えるかを GM が確認できます。

### チャットのロール別権限

[チャット](/manual/chat) のタブごとに、**ロール別の閲覧・発言権限**を設定できるようになりました。特定のロールだけが読める／書けるタブを用意できます。

- **チャットログの保存（書き出し）は、ロールに関わらず誰でも**行えます。

### 暗闇・視界・光源

テーブルに **3D の視界・光源・暗闇** の仕組みを追加しました。暗闇を有効にすると、キャラクターの視界や光源の届く範囲だけが見えるようになります。

- **見学は、全プレイヤーの視界を合成した範囲**が見えます。

詳しくは [暗闇・視界・光源のマニュアル](/manual/vision-lighting) を参照してください。

### ジュークボックス：効果音（SE）

[ジュークボックス](/manual/jukebox) で **効果音（SE）** を扱えるようになりました。

- 音源のタグを **SE** にすると、**BGM を止めずに、その上に重ねて**鳴らせます。複数の SE を同時に重ねることもできます。
- 各行のボタンで **▶ 再生 ↔ ■ 停止** を切り替えでき、再生・停止は参加者全員に同期されます。音量は **SE スライダー**で個別に調整できます。

## 🐛 不具合修正

- **カットイン** … SE タグを付けた音声が、カットインの演出として **SE 音量**で再生されるようにしました。
- **保存と読み込み** … 床へ移動したオブジェクトが、その後に読み込めなくなることがある問題を修正しました。

## ♻️ 改善

- **ピアの表示・プライバシー** … 名前を設定していない参加者を**先頭 6 文字の短い ID**で表示するようにし、接続まわりのメッセージに内部の生 ID を含めないようにしました。
