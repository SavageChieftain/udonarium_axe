# v1.18.2

2026-06-17 リリース

ブラウザを開き直すと **ユーザー ID が `???` のまま接続できない** ことがある問題を修正しました。

## 🐛 不具合修正

- **ブラウザを閉じて開き直すと ID が `???` のままになる問題を修正** … タブを閉じて開き直したり、PC を再起動したあとの初回アクセスなどで、ユーザー ID が `???` のままルーム一覧を開けないことがありました（ページを再読み込み＝ F5 すると直る／別タブでは再発する、という症状）。
  - 原因は、起動時の **設定読み込み完了の通知** が、それを待ち受ける接続開始処理よりも **先に発生してしまう**ことがあり（特に設定ファイルがブラウザにキャッシュされていて読み込みが速いとき）、その結果として接続の開始が一度も呼ばれないことでした。
  - 設定読み込み完了の通知を **後から受け取っても取りこぼさない** ようにし、タイミングやキャッシュの状態に関わらず確実に接続を開始するよう修正しました。**F5 による回避は不要** になります。

::: tip 接続まわりの安定化（v1.18.1 と合わせて）
[v1.18.1](/release-notes/v1.18.1) ではトークン発行サーバーのコールドスタート、本リリースではブラウザ起動時のタイミング問題と、`???` のままになる二系統の原因をそれぞれ修正しています。
:::
