# v1.34.0

2026-08-12 リリース

**卓が終わったあとに残るものが増えた**回です。記録から「まとめ」「記念写真」を作れるようになり、
配信に重ねるための画面が入りました。

## ✨ 新機能・改善

### 記録から「まとめ」を出せるようになりました

リプレイのワークスペースに **「まとめ」** が付きました。押すと、その記録がこうなります。

| 節               | 中身                                                      |
| ---------------- | --------------------------------------------------------- |
| **数字**         | 経過時間 / 発言 / ダイス / 演出 / ラウンド / 話した人の数 |
| **今日の称号**   | 不運王・賽の寵児・よく喋った人・いちばん削られた          |
| **ダイスの出方** | 人ごとに 振り数・平均・最高・最低・会心・大失敗           |
| **受けた増減**   | コマごとに ダメージ・回復・最大の一撃                     |

**「まとめを書き出す」** で Markdown として保存もできます。

出せないものは、はっきり「出せません」と言います。

- **誰が与えたダメージかは出しません。** 記録に残っているのは「値を変えた人」で、攻撃した人ではないためです（GM が敵の HP を減らせば GM の名前になってしまいます）。受けた側だけを数えています
- **ダイスの出方は v1.33.0 以降の記録だけ**です。それ以前の記録には出目そのものが残っていないため、復元できません
- **GM 限定の発言や密談は、PL のまとめには入りません**（動画・読み物と同じ扱いです）

### 卓の記念写真

まとめの画面に **「記念写真」** が付きました。その卓に出ていたコマの立ち絵を 1 枚に並べ、
部屋名と日付を焼き込んだ PNG を保存します。

- 並ぶのは**盤に出ていたコマ**だけです。しまってあるコマは写りません
- 24 人を超える卓では、入りきらなかった人数を画面に出します（黙って切りません）
- 立ち絵がこのブラウザに残っていないコマも、**枠と名前だけは残します**

### 配信オーバーレイ（OBS 用の透過画面）

接続パネルの招待リンクに **「配信用（透過画面）」** を足しました。この URL を OBS のブラウザソースに
貼ると、**盤面もパネルも出さず**、直近の発言と手番だけが透過の背景に出ます。

- **見学者のリンクを渡してください。** 通常の参加者として 1 枠使います
- **配信用に開いた画面は、卓の他の人には影響しません**（ノベルモードと違い同期しません）
- **密談・伏せたダイス・その役割に見えないタブは映りません。** 入室が終わるまでの一瞬も、
  狭いほうの役割で判断します

### リプレイの読み物書き出し（v1.33.0 から継続）

まとめと同じワークスペースから、小説・台本形式の書き出しも引き続き使えます。

## 🐛 修正

### 短い間に続いた増減が、1 回分しか記録されていなかった問題

同じコマの値を **1 秒以内に続けて動かす**と、記録が畳まれる際に**先の増減が上書き**されていました。
10 ダメージのあとに 5 ダメージを与えると「5」としてだけ残る、という状態です。

これから録る記録では両方が残ります。**すでに録った記録は直りません**（記録された時点で失われているためです）。
