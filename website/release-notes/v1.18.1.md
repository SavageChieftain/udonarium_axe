# v1.18.1

2026-06-17 リリース

ルームへ入る前の **接続（ID 取得）の安定性** を改善する修正リリースです。

## 🐛 不具合修正

- **起動直後・更新直後に接続できないことがある問題を修正** … PC の再起動・シャットダウン後の初回アクセスや、アプリの更新直後などに、ユーザー ID が `???` のままになり、ルーム一覧を開けないことがありました（ページの再読み込み＝ F5 で復帰）。原因は、トークン発行サーバーが起動直後（コールドスタート）に一時的な失敗を返したとき、再接続されずに止まっていたことです。
  - トークンの取得を **タイムアウト付きで数回リトライ** するようにし、サーバーが温まるまでの一時的な失敗を吸収します。
  - それでも失敗が続く場合も、**少し待ってから自動で再接続** を試みます（回数の上限あり）。
  - これらにより、多くのケースで **手動での再読み込み（F5）なしに自動で接続** できるようになりました。サーバー自体に到達できない場合は、従来どおり上限到達でエラーを通知します。
