# v1.34.1

2026-08-12 リリース

**中身の整理**が主な回です。遊び方は変わりません。ただし、整理の途中で見つかった**古くからの不具合が 3 つ**
直っています。

## 🐛 修正

### ノベルモードで Ctrl + キーの操作が奪われていた問題

ノベルモード中は、**Ctrl（Mac では ⌘）を押しながらのキー操作まで**画面の操作として拾っていました。

| 押したもの   | これまで                             | これから             |
| ------------ | ------------------------------------ | -------------------- |
| **Ctrl + A** | 全選択が効かず、自動再生が切り替わる | 全選択が効く         |
| **Ctrl + S** | 保存が効かず、立ち位置の案内が開く   | ブラウザの保存が出る |
| **Ctrl + L** | ログの表示が開く                     | ブラウザ本来の動き   |

Ctrl **単独**での早送りは、これまでどおり使えます。

### 動画の書き出しで、絵の読み込みを 1 枚ずつ待っていた問題

書き出しの前に立ち絵や背景を読み込む処理が、**1 枚ずつ順番に**待っていました。使っている絵が多い記録ほど、
書き出しの開始までが長くなっていた状態です。まとめて読み込むようになり、**絵の多い記録ほど待ち時間が短くなります**。

### マップエディタで、余計な描き直しが起きていた問題

- 画像を配置しようとしている間、**盤面を描き直すたびに絵の読み込みを始めて**いました
- 図形や線の種類を**道具箱で選び替えただけ**でも、地図全体が描き直されていました

どちらも、描く前に必要なものを用意する形に改めました。**大きな地図ほど軽くなります**。

## 🔧 内部の整理

遊ぶうえでの違いはありませんが、記録として残しておきます。

- 90 種類の演出の描画が 1 ファイル（4161 行）にまとまっていたのを、**種類ごとに分けました**。
  粒子側（1502 行）も同様です。演出を 1 つ足すのに 2 か所を直す必要が無くなりました
- マップエディタの「描いている最中の下書き」の描画を、コンポーネントから独立させました
- キャラクターシートの項目の追加・移動、ノベルモードのキー割り当てなど、
  **これまで画面ごと動かさないと確かめられなかった部分**に試験を足しました（テストは 5589 → 5630 件）
